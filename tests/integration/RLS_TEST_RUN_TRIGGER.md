# Déclencheur des tests RLS Supabase

Fichier de suivi sans code exécuté par l'application. Son ajout sur `main` déclenche le workflow GitHub Actions qui exécute les tests d'isolation à deux comptes sur le projet Supabase de test dédié, si les sept secrets requis sont configurés.

Ne jamais y ajouter de secrets, d'identifiants ou de données personnelles.
